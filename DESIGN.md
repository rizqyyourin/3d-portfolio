# Portfolio visual direction

This records the visual direction already present in the portfolio. It is a reference for future UI work, not a request to redesign the current experience.

- Identity: an editorial, interactive 3D portfolio for Ahmad Rizqy Yourin.
- Personality: quiet, precise, technical, and curious.
- Palette: warm off-white surfaces, deep charcoal text, and restrained olive-green accents.
- Typography: readable sans-serif prose with a mono face for interface labels and navigation metadata.
- Composition: a fixed 3D workspace framed by sparse HUD controls and chapter-based navigation.
- Motion: purposeful and cinematic; chapter transitions and ambient 3D motion pause for reduced-motion users or focused content.
- Dials: ENERGY 3 / RHYTHM 3 / MOTION 3.
